常見問題 FAQ

收唔到驗證碼？ 請檢查垃圾郵件，並確認輸入的是 @link.cuhk.edu.hk 或 @cuhk.edu.hk 電郵。

No sign-in code? Check your junk folder and make sure you used an @link.cuhk.edu.hk or @cuhk.edu.hk address.

點樣刪除帳戶？ 個人 › 刪除帳戶。

How do I delete my account? Profile › Delete account.

點樣檢舉內容？ 在活動或學會頁面按「⋯」›「檢舉」。

How do I report something? Tap ⋯ › Report on the event or society page.

想登記學會？ 學會 › 登記學會，管理員審核後即可發佈活動。

Want to list your society? Societies › Register society. Once an administrator approves it you can post events.
